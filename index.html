02 Jan 2026 — Jun 2026

Portfolio Report Agent (Actuals vs Forecast Automation)

Business Analysis · Reporting Automation · Portfolio Operations

Every Monday, PMs were manually rebuilding the same Actuals vs Forecast deck—pulling project dates, task counts, and status notes from different Notion databases and reformatting Gantt views by hand. I configured a Notion custom agent with a weekly Monday 8:00 AM trigger, read access to canonical Projects and Tasks databases, and strict rules: reference reports define format only; live metrics always come from source databases.

Case study
  • Problem: Weekly portfolio reporting was manual copy-paste across a 7-project portfolio at co-op start; 2 projects were later halted for resource crunch, leaving 5 active.
  • My role: Defined reporting requirements, mapped data sources, wrote agent instructions, set weekly trigger, validated output against PM acceptance criteria.
  • Solution: Notion custom agent → executive summary, forecast vs actual variance, portfolio Gantt, one project deep dive, top risks, and weekly action items across 5 active projects.
  • Outcome: Cut weekly reporting prep from about 2.5 hours to a 20-minute PM review (down about 87%); every metric traces to the source databases, and leadership receives one canonical report every Monday at 8 AM.
Notion AI Agents Projects Database Actuals vs Forecast Portfolio Reporting Stakeholder Reporting Automation
