User Stories & Acceptance Criteria

Epic: Portfolio Actuals vs Forecast Automation · Sprint: Reporting Ops · Author: [Redacted] · Date: Feb 2026

Epic Goal

As a portfolio PM, I need a weekly Actuals vs Forecast report generated from canonical databases so that leadership receives one accurate status view without manual copy-paste (~2.5 hrs → ~20 min review).

US-01 · Weekly report trigger

As a portfolio PM, I want the agent to run every Monday at 8:00 AM, so that the report is ready before the weekly cadence meeting.

Acceptance criteria:

  • Scheduled trigger fires at 8:00 AM ET each Monday
  • Manual re-run available in Notion without changing schedule
  • Failure notification logged if data pull incomplete
US-02 · Live data integrity

As a PM, I want all metrics pulled from Projects DB and Open Tasks, so that no stale figures from prior decks appear in the report.

Acceptance criteria:

  • Reference reports used for format/layout only—not live metrics
  • Each executive summary row traces to Projects DB record
  • Task counts match Open Tasks DB at generation time
US-03 · Portfolio executive summary

As leadership, I want a single-page portfolio summary for all active projects, so that I can spot variance without opening five separate decks.

Acceptance criteria:

  • Covers 5 active live projects (7 at co-op start; 2 halted excluded from active roll-up)
  • Columns: status, phase, forecast dates, actual dates, variance flag, task completion
  • Halted projects marked separately—not counted as active
US-04 · Gantt & deep dive

As a PM, I want a portfolio Gantt and one project deep dive per week, so that we rotate visibility across the portfolio.

Acceptance criteria:

  • Portfolio-level Gantt with forecast vs actual bars
  • One full deep dive: milestones, task tie-out, risks, actions
  • Mermaid-compatible output in production Notion workflow
US-05 · PM review workflow

As a PM, I want to review and publish in ~20 minutes, so that reporting prep does not consume half my Monday.

Acceptance criteria:

  • Draft generated before 8:15 AM
  • PM validates variance flags and adds meeting-note enrichment when available
  • Published report is the single canonical version for the week
